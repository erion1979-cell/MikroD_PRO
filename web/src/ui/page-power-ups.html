    Converter

    Any Ethernet-to-RS485 converter works if it runs as a Modbus TCP gateway (Modbus TCP ↔ RTU). MikroDash only needs its IP address and port; the make does not matter. Plain transparent mode (raw serial over TCP) does not work.

    • Serial side: 9600 baud, 8 data bits, no parity, 1 stop bit (9600 8N1).
    • Network side: TCP server on port 502, static IP address on the site LAN.
    • E30-485: Port1 → Advance → Modbus Gateway ON, Data Cache OFF, Poll OFF.
    • ZLAN 5143, 5243A, 7144, 7144N2: conversion protocol Modbus TCP<->RTU; turn the storage Modbus gateway off (untick RS485 multi-host support and bus conflict detection), or it keeps polling the inverter by itself and can show old values. Keep P2P/cloud off.
    • ZLAN 7104 is not supported: it has no Modbus gateway mode.
    • Several units on one converter need different slave IDs, set on each unit.
    • Security: Modbus has no password. Keep converters on their own VLAN or firewall them so only MikroDash reaches port 502, block the setup ports (E30: UDP 8168, ZLAN: UDP 1092), change the web passwords, and never forward Modbus to the internet.
